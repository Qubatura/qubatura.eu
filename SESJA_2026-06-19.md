### Mgła: sprite'y → shader (`atmosphere.js`)
- Pełnoekranowy **fragment shader** na planie z=0 (w `scene`, więc Pass 1 refrakcji go łapie → sygnet zagina mgłę).
- `fbm` 3 oktawy + tani **domain-warp** (1 okt) + wyraźny **ukośny drift** `flow=(0.50,-0.34)` → mgła „leje się".
- Tint i chmury działów czytane z `navFX` (`target/intensity/activeDiv`) — **kontrakt nietknięty**; `cloudFalloff` odwzorowuje stary gradient.
- `CustomBlending` pure-add RGB, `alpha=luminancja` → CSS `#planet-bg` prześwituje.
- **Corona została** jako system linii (LineBasicMaterial), karmiona `navFX`.
- Easing chmur niezależny od FPS (`delta * CLOUD_EASE_RATE`).

### Glow sygnetu: stos linii → sprite z rozmytej tekstury (`signet.js`)
- Sylwetka sygnetu (kontury+dziury, even-odd) → canvas 512 → `ctx.filter blur` → `CanvasTexture` → kwadratowy plan (dziecko `group`, `flipY=false`).
- Materiał: premultiplied additive + **dithering IGN** → koniec banding/ziarna i „technicznych" obrysów.
- Dwie warstwy: szeroka (`blur 48`, `#5B2EFF`, op 0.55) + ciaśniejsza (`blur 14`, `#9B8CFF`, op 0.95) + **ostry kontur** `LineBasicMaterial` 1.0 (czytelność idle, bez zmian).
- `FILL=0.48` (udział sygnetu w canvasie; **niższy = szerszy rozlew**, rozlew ∝ `blur/FILL`).
- **Balans per dział** = mnożnik JASNOŚCI koloru (`GLOW_GAIN`, NIE opacity — opacity klipuje do 1). Events 1.15 / Studio 0.88 / Lab 0.6. HEX-y w nav/tint/HUD nietknięte.
